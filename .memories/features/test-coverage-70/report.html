What was deliberately excluded

  • C# sidecar (2,033 lines) — ClrMD-bound; meaningful tests need a real crash-dump fixture. Out of scope per decision.
  • Whole-file Rust exclusions: src-tauri/src/main.rs (Tauri entry) and process/kill.rs (taskkill/libc platform forks, exercised indirectly).
  • src-tauri command wrappers stay 0% — after the refactor they are thin Tauri plumbing, exercised only through the app; they remain inside the denominator honestly.
  • React rendering code — the frontend metric covers the extracted *Logic.ts modules only, by design.

Behaviour changes needing sign-off

  • Bad CLI path now prints code-basics: {e} — the scan-failure message lost its "could not open <path>:" prefix (the error already names the path).
  • Compound-run start errors now aggregate all member failures joined with "; " instead of reporting only the first.

Notable finds along the way

  • The process:: tests hang forever when sh isn't on PATH (spin-wait with no timeout) — this wedged the first coverage run for ~2h. Fixed with 30s timeout guards; documented in CLAUDE.md's command list.
  • A Codex trust-key parsing quirk: a backslash-escaped TOML basic-string project key reads as untrusted (safe direction) — characterized in a test rather than changed.
  • vitest 4's coverage table silently omits fully-covered files — read coverage-summary.json, not the terminal table.
  • One flaky cb-core lib failure in an intermediate coverage run; details lost to output truncation, immediate full rerun green. Worth watching.
